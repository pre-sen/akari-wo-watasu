# 灯りを渡す — 二つの鍵 v2.3「協力者の得意分野」

- v2.2.1の静かな雨音・BGM、開始ボタン連動、音量スライダーを維持。
- 担当者候補に「できること」と「得意分野」を表示。仮選択は無料、依頼確定で1行動。
- **得意分野は特定イベントの連絡・調整を同じ1行動にまとめる効果**。本人の同意、経路や場所の安全確認、実際の了承・申し送りは省略しない。
- 例：地域の案内人が移動担当のとき、交通の変更が起きたら、経路の再確認と移動担当への調整を同じ行動で行える。
- 夜間支援担当（連絡）・母親（連絡）・父親（連絡）・交流センター職員（見守り）にも異なる得意分野を設定。
- 成立した得意分野はプレイログと終了後の振り返りに残る。
- シードの初期条件と予兆カードの組合せは従来と同じ。得意分野を使う場合の必要行動数は変わることがある。
- チュートリアルは従来の14段階を維持し、新しい候補説明だけ追加。
- 今回は小規模な調整実験。難易度のバランスは再検証が必要。ナイトメアのクリア保証はなし。
